# 永蚀 0.7：沉井上行

这轮把主要验证场所移回探索地图。方向是从地下往地表上行，不使用随机房间、随机宝箱位置或随机刷怪。复用旧版的上行概念、程序化资产、玩家物理和武器系统，重新手工配置空间、生态、收获与回程。

## 已实现的空间

一张 3000 × 3300 的连续地图，镜头跟随玩家；由底部气闸向上穿过七个高度层，包含十个命名区域、21 个固定敌人和 13 处交互点。13 处包括八个宝箱/核心匣、三个医疗点、两个升降台开关。没有门传送，也没有必须获得二段跳才能继续的主路线。

```text
                    天光母巢（可选首领、核心匣）
                              ↑
                 地表货运站 ── 上井升降台
                    ↑                 ↑
              冷凝栈道             破顶温室
                    ↑                 ↑
                 检修中庭 ─── 下井升降台
                    ↑                 ↑
              断电锻台             孢囊温床
                    ↑                 ↑
               西泵房               东根室
                    ↖               ↗
                    沉井气闸（出发 / 撤离）
```

上下层平台不是同一条直梯的重复：从泵房到锻台的上行口向西移，从温床到中庭的上行口向内侧移；冷凝层与温室的下一处上行口再次错开。这样进入新层后，需要穿过一段有人居住、有人守护的空间，再继续向上。交汇层允许改走另一侧，S 可以从单向平台向下返回。

地图仍是可迭代的固定灰盒：踏步间隔服务于现有跳跃高度。房间轮廓、装饰和运动表现还没有达到最终美术与关卡精度，不把尺寸或检查通过当作“好玩”的证明。

## 每处遭遇的作用

| 地点 | 地形与生态安排 | 收获及目的 |
| --- | --- | --- |
| 沉井气闸 | 安全出发层；抬头可见两侧第一批携带者，先选择猎取方向 | 补给柜给一针；左侧独立气闸用于撤离，避免与升降台交互冲突 |
| 西泵房 | 入口一只低血量冲撞腺爬行者；靠泵体背墙的回收者携带压电骨 | 先获得动作改造，再遇到可以撞墙的目标；工具箱放在泵体上方，提供增压筋和 35 样本 |
| 东根室 | 近地爬行者携带刻印眼；高位共鸣索射手形成斜向火力 | 优先处理射手后可占据其高台；样本柜再给一层刻印眼和 35 样本 |
| 断电锻台 | 放电髓回收者靠近矮墙；侧面爬行者补充击退模块；上行口在墙后 | 撞墙组合完成后立刻有空间试用；上方热压箱给攻速和 65 样本，需要偏离主通道攀取 |
| 孢囊温床 | 三只近地单位相隔约 130–160，射手在后方高位；掉落传播、印记、回血与攻速 | 密度支持印记传导和死亡传播；背后的高台箱给共鸣索叠层与 65 样本 |
| 检修中庭 | 无新增守卫；左右两路在宽平台交汇 | 一次性治疗 35、补一针；从这里开启回底部的升降台，形成第一次“撤还是继续”的节点 |
| 冷凝栈道 | 地面重型单位和高处射手分层；掉落冻结与碎冰 | 需要在近身与高处目标间切换；偏离主路的冷藏箱再给冻结层数与 95 样本 |
| 破顶温室 | 一只活动守卫、两只看得见的休眠守卫；休眠者会被攻击唤醒，也会被开箱唤醒 | 活性温床匣给回血和 120 样本；开箱前可以先处理守卫，或取箱后迎战 |
| 地表货运站 | 两侧近战与中上方射手，矮掩体提供击退与避弹机会；敌人生命提高但不无限增长 | 成型组合的第二轮实战；震荡肺、高热、易伤等补件；右端有最后补给，中央开启第二段升降台 |
| 天光母巢 | 母体与两只辅助单位；两侧高台；不封入口、不要求杀首领才能回去 | 母体 1600 生命；击杀收益 180；之后才能打开 250 样本的核心匣，取得群猎眼 |

敌人具有固定归属区域和追击活动范围。未接近的生态不会在屏幕外互相挤落，也不会隔着数层地板全图追人。击退仍能让敌人落到下层；掉落落在实际下方平台，不再固定到旧单屏地面的高度。母体按自身高度站在顶部平台上。

## 回程与取舍

下井升降台连接中庭与底部，上井升降台连接货运站与中庭。必须先到上方开关通电；按 E 登台后连续移动，移动或跳跃可离开。开关是本次出行的状态，新一趟需要重新探索，未沿用旧地图的永久回路图捷径。

宝箱只领一次，指定模块是可预期的目标，不摇随机结果。打开模块箱会进入已有的器官取舍界面，敌人暂停；关掉界面后恢复战斗。主目标不是清空敌人，而是带着自己愿意保住的收获回到底部，按住 E 两秒撤离。

## 推荐 build

探索中按 **R**，或从 Tab 地图点击「推荐 build」。依据已安装的模块数量排序，不评定“最强”，不替玩家自动换装。

| 推荐 | 核心玩法 | 推荐武器 | 主要猎取路线 |
| --- | --- | --- | --- |
| 撞墙放电 | 冲撞 / 手雷击退 → 撞墙充能 → 第三锤放电 | 重锤＋手雷 | 西泵房 → 锻台 → 货运站 |
| 印记扩散 | 分配命中挂印 → 集火击杀 → 传导与传播 | 手炮＋无人机 | 东根室 → 温床；核心匣补最后一种 |
| 冻结碎冰 | 连续命中冻结 → 重击碎冰与易伤 | 重锤＋炮台 | 下层先取得辅助模块，再进冷凝栈道 |
| 回生燃盾 | 击杀回血溢出转盾，高热输出后散热补盾 | 步枪＋盾 | 温床 → 破顶温室 → 货运站 |

每张推荐卡显示六种模块、当前拥有层数、缺失来源、操作方式和代价。点击追踪后，HUD 显示下一个缺件所在区域和方向，目标实体位置出现标记；取得后自动转向下一个缺件。来源会排除已击杀敌人、已开箱子，并纳入地面掉落。

探索中追踪不会直接发模块。训练场仍有六套一键装配预设，可用于试机制和数值；本轮四套推荐则全部有这张地图上的实际来源。

- 生产构建和 TypeScript 检查通过；Phaser 分包仍有体积提示。
- `scripts/ascent-browser.js`：六项检查通过，用真实方向键与跳跃从底部沿最终西线登顶；仅开启无敌以隔离通路验证，没有传送、改移动速度或改跳跃物理。这不算无辅助出行。
- `scripts/ascent-interactions.js`：八项检查通过。受控位置和敌人状态下，实际鼠标射击验证滚动镜头瞄准；键盘完成器官接入、宝箱、推荐更新、升降台下行、走回气闸和按住 E 撤离。不能替代真人完整战斗评价。
- 截图在 `output/playwright/ascent-map.png`、`ascent-builds.png`、`ascent-crown.png`、`ascent-extraction.png`。

真人下一轮优先观察：第一趟是否自然理解左右路线的差异；宝箱是否值得绕路；中庭是否发生真实撤退考虑；带着成型组合进入上层，战斗方式有没有变化。若只是顺着楼梯跑过去，优先调整某一层的入口、视线与敌人位置，而不是继续扩张地图尺寸。
