这一趟为什么值得玩

玩家进入一座被机械生态侵占的地下泵站，逐步学会利用环境和器官；找到值得带走的物资后，回程重新遇到自己曾经影响过的生态。整体向上深入，局部下探和横向绕行。地图要有足够的探索容量，不以压缩成几个房间解决节奏问题。

一趟可以是很短的回本出行，也可以是深入探索。15–25 分钟仅是首次深入试玩的观察窗口，不是倒计时、刷怪时刻表或必须走满的流程。下面八段是八种经历，不等于八个房间；一段可以跨多个空间，同一处也可以承担去程和回程的不同经历。

这趟最想听到的玩家复述：我认出了刚才见过的那只怪，它吃到了我留下的东西；我知道另一条路，但带着货走不了，于是自己作出了选择。

01 / 出门就有事做：废弃维修工位

目标感受：我能应付，而且获得的能力马上有地方试。

进入视野：气闸外是一段水平维修通道。前方一只失控维修机械反复撞击卡死的工作台；它的动作先作用于物件，玩家靠近后才转向玩家。门口能看到侧身绕开的距离与可跳上去的设备顶。第一屏不安排长梯、菜单或长搜索。

行动：直接打；跳上设备观察攻击；诱导它撞向实墙后反击。走道没有锁门，也可以退回气闸。先只展示一种清楚的攻击，不叠远程夹击。

收益：固定放置的这只个体携带冲撞腺，击败后靠近自动接入。前方可选的小凹室有一只弱机械，背后是实墙，让玩家有机会试出击退、撞墙的结果；不强迫使用某种武器才能通过。

空间由此决定：偏长的水平工位、一个有实体碰撞的检修设备、一个可退回的入口、一面适合撞击的墙。设备高度允许普通跳跃，不用梯子；上方不是铺满跳台，而是一处明确可利用的工作面。

回程再经过：仍是气闸前的缓冲段。深处威胁不能无限追入出生门内；追击边界通过关门或实体通道表达，不能靠隐形范围让敌人突然忘记玩家。

02 / 第一次看懂生态：排污观察口

目标感受：它在吃东西，我可以干预，也可以不管。

进入视野：主路经过半层高的巡视步道，下方是积有机械尸骸的排污槽。栏杆或窗口允许观察，阻止远程攻击直接打到观察者。一个幼体从侧边食物口接近尸骸，走过去、停下来进食；食物的消失和身体获得的器官有可见变化。

行动：沿巡视步道离开；从侧边短落差下去打断进食；等它吸收后猎取；清掉食物，让后来的怪无物可吃。入口处就能看到下方的退出坡道，不用跳下去之后才发现退路。

生态条件：开局配置真实尸骸和附近幼体，位置为行为提供机会，但不按玩家进入播放动画、不强制成熟、不补刷“演员”。尸骸被玩家或其他怪先处理，这次观察就可能不同。可见特征、器官和个体身份保持连续。

空间由此决定：一条安全观察线与一条实际介入线，两者不能重合；下方既有食物也有逃离口。猎手的较远栖息区通过地面通道接到这里，未来能走入争食。它不需要爬玩家专用跳台才能到达。

收益：一件具体的电池或伺服件藏在排污槽边，价值足以让下去成为合理选择，但不让不下去的玩家错失基础战斗能力。

03 / 第一次有依据地选路：隔墙看见货物

目标感受：我知道两边大致意味着什么，我想选其中一边。

进入视野：巡视步道终点能透过货运栅门看见成排货箱和巡逻机械；门从远侧才能打开。向右是宽阔的旧装卸道，远处有稳定灯光与货运标识；向左是穿过排污设备的维修路，能看见散落尸骸和进食痕迹。没有“左安全 / 右危险”的抽象选项按钮。

右路：工业设施，长视线被货架分段遮挡。主要获取具体零件与普通货物，敌人武器预警清楚，正面交战较多。地面连续，未来可用于运输。

左路：较短但更曲折，穿过食物与捕食者活动区。可以走设备上方避开下层冲突；器官机会更多，货物较少。跳跃用于观察、绕行和切入，不是连续赶路考试。

两路汇入主泵厅的不同高度和侧面。汇合点能认出同一台大型泵机，而不是靠房间标题确认位置。两路收益允许互补，但都能独立支撑继续探索，不能一条路线垄断基本生存模块。

回程价值：从仓储侧打开先前看见的栅门，直接回到巡视步道附近。开门前后应能看见熟悉地标，立即理解少走了哪一段路。

04 / 构筑第一次发挥：绕泵战斗

目标感受：刚才拿到的能力在这里帮助了我，而不是数值已经大到什么都秒。

进入视野：大型泵机占据中间，下部有能绕到另一边的通道，上部有一段真实检修桥。左路到上侧观察口，右路到下侧地面。入口都给出退路与第一只敌人的预警，不在落地瞬间形成包围。

交战：少量敌人分布在泵机两侧，不同时挤到入口。近战机械逼近、远程单位利用另一侧视线，玩家可以用实体泵机断开射线，再跳桥、冲刺或下砸切入。墙边适合撞击，局部连通空间适合传导；不要求某个 build 才能解决。

收益：获得不同于首战器官的能力来源，优先让已收集能力之间出现一次可理解的组合机会。普通击杀不喷满屏多层器官；成长预算见后文。

空间由此决定：这是地图中少数较宽的交战空间。它之所以大，是为了给移动和敌人分工留空间；周边空间不复制它。检修桥不能变成敌人永远无法攻击的站桩射击台，要保留敌人的合法接近或远程威胁，同时保留玩家观察缓冲。

离开之后：战斗尸骸落在实际死亡位置。排污区的食腐者能够沿地面进入下层，玩家可能在回程看到尸骸减少、个体改变。没有尸骸或食腐者已经被清掉，就不强制制造这件事。

05 / 放松并看见下一次诱惑：泵后值守台

目标感受：我已经有所收获，可以整理；再往上似乎有更好的东西。

进入视野：绕过主泵后进入一段紧凑、光线稳定的值守台。这里没有初始巢穴或必经巡逻，能从窗口回望刚才的战场。不是用“清空所有怪”才能解锁的休息房。

内容：一本具体书籍、一份指向控制层和货运电力的设施图。物件摆在桌面上，保持短交互；不再用全套站桩搜索重复填满每个角落。这里允许查看构筑、丢弃不想要的器官和考虑撤离。

诱惑：窗外或对面隔断后可以看到吊装设备；控制线与断电的运输设施让玩家理解需要去哪里恢复供电。去控制层和回出生气闸的路在此明确分开，继续深入是选择。

可选内容：有职业的被困人员可作为后续独立支线预留空间；第一版不实现护送时，不放一个假人交互冒充已完成救援玩法。

06 / 深入有新问题：被侵蚀的控制层

目标感受：我已经熟练，但不能沿用下层的站位解决全部问题。

空间变化：人类的直线检修通道被神造结构局部侵占，视线与落脚点发生变化。只在这一段引入浮游敌人与上下交叉威胁。普通通路仍有稳定地面，危险跳跃支路换取高价值目标，不把整个上层做成跳跃关。

行动：先从边缘侦察；沿掩体推进；走上侧支路绕过守在地面的强个体。强个体的能力组合在遭遇前至少有一次可见表现，危险来自组合和位置，而不是无预警地一击致死。

目标：恢复货运供电。开关应在有设施逻辑的位置，操作后看到电力沿线亮起，地图标明已恢复的货运撤离。供电不触发凭空防守波，也不要求先击杀全图最高级个体。

支路：封存资料与星骸放在这里的可选深处。蓝图需要成功带回后结算；星骸的跨局一次性规则尚未确认，本版只预留地标，不能擅自实现成永久能力提升。

07 / 拿起之前就能算清：吊装设备

目标感受：我想拿，但我知道会失去什么便利。

进入视野：目标设备在检修架上，设备下方就能看到通向货运站的缓阶与运输地面。玩家轻装来的上侧维修口明显更窄、更高；不能等拾取后才用弹窗宣告禁止通行。

行动：先侦察运输路、确认电力；拿起就走；先清附近威胁；放弃设备而搜旁边的小型零件。拾取是明确主动操作，不能像器官一样路过就自动背上大件。

运输路径：大件沿连续地面、缓阶和低坡下降至中段货运站；只在确有巨大落差的位置考虑货梯。给两条运输绕路：较短的一条重新经过泵厅侧缘，较长的一条走外侧装卸廊。两条都必须能实际搬运；轻装维修口是第三种弃货选项。

货物压力：重量主要改变路线、加减速和脱离能力，不让角色完全失去战斗操作。随时可放下再打，地上仍是同一个物件。死亡与成功撤离分别记录损失和具体带回物品。

08 / 熟悉的地方发生了变化：带货回程

目标感受：我理解危险的来源，也还有选择，不是被导演强行安排堵门。

可能发生：去程泵厅留下的尸骸被食腐者吞噬；猎手沿食物通道进入泵厅侧缘；成熟个体扩大活动范围。玩家能通过器官特征、体型变化和行进痕迹认出它。并非每局都必须有 Apex，更不把 Apex 在固定时间搬到回程口。

选择：放下货物交战；利用泵机遮挡绕过；带货走更长的外侧装卸廊；弃货走轻装维修口；放弃中段撤离、带普通物资返回气闸。回程门不会自动锁死，玩家先前清巢或处理食物也应得到更平静回程的回报。

没有发生：若玩家清理得干净、较早返回，允许一路顺利撤离。不能为了凑“事故”偷刷强怪。试玩要验证的是变化具有机会和可追溯性，不是每局强制演出同一故事。

结束：货运站已供电即可撤离，不附赠守点波。气闸从始至终允许普通物资撤离。第一次空手撤离也是有效决定，不应被当成失败流程。

空间关系由上述经历推出

气闸 → 水平维修工位 → 排污观察口 → 装卸道 / 维修路二选一 → 主泵厅 → 泵后值守台。

值守台向上连控制层，侧向连吊装区；控制层恢复货运电力。吊装区向下接两条真实运输路，再到中段货运站。主泵厅及其侧缘是去程与回程重复识别的地标。

回出生的捷径在仓储远侧打开；怪物的食物通道接排污区与泵厅下层。两者不要混为同一条狭窄玩家跳跃通道。地图知识、运输路线和生态迁移各自有物理依据。

房间数量、总宽高和回环个数暂不锁死。画图时优先保证战斗空间、观察距离、路径长度和尺度变化，再验证整体容量是否足够；不直接把相同房间放大来满足“地图大”。

同步约束成长：不能两分钟进入互秒

以下是待试玩校准的设计目标，不是现有程序已达到的结果，也不是按时间限制玩家成长。

前段资源分布让玩家先得到一个新能力、试用，再获得互补能力。探索前几处普通遭遇后，目标是约 2–4 种器官并有少量叠层；这是布置预算，不是身体槽位上限，也不禁止主动冒险获得更多。

主泵厅检验已有能力的组合，上层再引入更复杂的敌人组合。携带同样能力的敌人也要遵守预警、冷却、触发间隔和地形规则，不能用一帧内连锁触发把满血玩家直接结算掉。

测量而不猜测：记录每次玩家伤害峰值的来源、连锁触发次数、敌人击杀时间、玩家连续受击间隔，以及能否从一次失误中退出。分别检查无限叠层、恢复/护盾循环、冻结控制链和敌方多器官爆发，不能靠全体生命乘一个数修复。

普通敌人应允许强构筑快速清理；危险个体要留出至少一次辨识和应对机会。生存成长不能只靠无限抬高最大生命值追赶伤害；恢复与控制也需要触发节奏，避免成型后长期无敌。

画下一张图前的逐点验收

  • 每个入口标注首个可见目标、首个威胁和退路；不只写房间名称。
  • 每段高差注明为什么存在：观察、绕行、切入、奖励或运输。只有赶路作用的竖井优先删掉。
  • 主路线无需长梯、极限二段跳或强制蹬墙；难跳只用于可选收益。
  • 战斗房、观察段、搜索支路和缓冲段使用不同空间结构，不复制“空腔＋两块平台”。
  • 每个食物点同时画食腐者入口、猎手入口和玩家观察线；怪物活动路线不可穿墙或跨越其无法通过的高差。
  • 每件重货都画一条从摆放点到撤离点的连续搬运线，另验证备用路线；不用区域图上的一条边冒充可达。
  • 捷径先能被发现，后能从远侧打开，打开后立即认出旧地点。
  • 分别走通早撤、左右两种深入路线、带货回程、弃货回程，以及生态未成长的平静局面。

这次交付与后续边界

这次交付的是上述具体体验、遭遇与空间约束；没有改游戏地图、敌人数值或生态实现。下一张审核图按这些约束逐处绘制，不能把旧 A/B 图继续换名字使用。图确认后才接入游戏；实现验收同时覆盖路线、成长和可见生态，不能再用测试通过代替体验判断。
