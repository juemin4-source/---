# 0.9：打击感与狂热

0.9 不改地图和模块规则，只解决一个问题：**战斗从"还行"变成"爽"**。
做法是把每一次攻击、命中、击杀都接上反馈，并让"连续进攻"本身产生收益。

## 一、反馈层（Juice）

每次战斗事件现在都会产生一套可感知的结果，而不是只掉一个数字。

| 事件 | 顿帧 | 镜头 | 画面 | 声音 |
| --- | --- | --- | --- | --- |
| 命中 | 12ms | 轻微震动 | 火花 + 伤害数字 | 短促撞击 |
| 重击 / 下砸 / 爆裂 | 70–90ms | 强震动 + 后坐 | 冲击环 + 碎块 | 低频撞击 + 噪声 |
| 击杀 | 55ms | 震动 | 尸体被抛出并翻滚 | 击杀音 |
| 母体击杀 | 240ms | 强震动 + 推近 | 0.9 秒慢动作 + 闪光 | 长尾低频 |
| 破韧 | 90ms | 中震动 | 金色冲击环 + 破韧框 | 中频爆音 |
| 完美闪避 / 完美格挡 | — | 推近 | 0.4 秒慢动作 + 闪光 | 高频上扬 |

- **顿帧（hitstop）**：命中瞬间把模拟时间缩放到 0，画面继续播。不叠加，取最强的一次；轻击有 0.09 秒冷却，避免高攻速武器把画面卡住。
- **慢动作**：只给母体击杀与完美闪避/格挡这类"值得纪念"的时刻，0.2–0.25 倍速，末尾平滑恢复。
- **镜头**：震动由 trauma 平方驱动（衰减快、起手重），另有射击后坐与击杀推近；震动只叠加在平滑跟随之上，不会污染镜头跟随本身。
- **粒子**：火花、碎块、冲击环、拖尾四种，全部程序生成，上限 900。
- **尸体**：击杀后敌人不再瞬间消失，而是被击飞、翻滚、落地淡出（母体 1.5 秒，普通 0.9 秒）。
- **音效**：合成音从单振荡器升级为「振荡器 + 噪声脉冲 + 压缩器」，撞击类事件带滤波噪声，因此有实体感；同名音效 20–30ms 限流，不糊。
- **起手预警音**：敌人进入 windup 时播放上扬警示音，精英更响。

## 二、狂热（连杀）

连续击杀会进入狂热状态，这是 0.9 的核心爽点。

| 连杀 | 档位 | 攻速 | 移速 | 伤害 |
| --- | --- | --- | --- | --- |
| 3 | 连杀 | +12% | +8% | +15% |
| 7 | 狂热 | +24% | +16% | +30% |
| 13 | 屠宰 | +36% | +24% | +45% |
| 22 | 永蚀 | +48% | +32% | +60% |

- 连杀窗口 4 秒，母体额外 +2 秒；**受伤扣 1 秒**，所以"打得凶"和"不挨打"是同一件事。
- 每次击杀返还体力，并把冲刺冷却压到 0.12 秒以内——进攻循环变成「冲刺进场 → 击杀 → 冲刺出场」。
- 狂热同时提高削韧（每档 +25%），越连杀越容易压着敌人打。
- HUD 显示连杀数、档位、剩余时间条与当前加成；玩家身上有随档位变色、跳动的光环。
- 2 连杀起有「双杀 / 三杀 …」横幅，跨档位有档位横幅。

## 三、僵直与破韧

0.9 之前，敌人起手后只能躲；现在可以用输出打断它。

- 敌人有韧性条（普通 30 / 母体 80），直接命中削 7，重击削 30，狂热再乘削韧倍率。
- 韧性归零：打断当前起手，进入硬直（普通 1.15 秒 / 母体 0.7 秒），期间**易伤 +45%**。
- 破韧后有 1.6 秒以上冷却，不能永久锁死敌人；韧性每秒恢复 6。
- 韧性低于 55% 时敌人脚下显示金色细条，破韧时显示金色框与「破韧」标记。

## 四、处决线

敌人生命低于 28% 时受到的直接伤害 ×1.6。
效果是每个敌人都以"越打越快"收尾，而不是最后一点血磨时间。

## 五、实测

自动测试从 83 项增加到 96 项，新增 13 项覆盖顿帧不叠加、连杀窗口、多杀横幅、母体慢动作、受伤打断连杀、完美闪避、破韧与冷却、处决线、击杀返还、尸体清理。

浏览器实测（`scripts/verify-feel.mjs`，真实键鼠 + 真实武器）：

| 检查 | 结果 |
| --- | --- |
| 实战击杀累计 | 12 |
| 连杀记录 | 12，进入狂热档位 2 |
| HUD 连杀计数 | 显示 |
| 粒子系统 | 104 个活动粒子 |
| 横幅 | 狂热 / 8–11 连斩 |
| 顿帧帧时间缩放 | 0 |
| 顿帧吃掉模拟时间 | 0.033s / 墙钟 0.122s |
| 镜头震动位移与旋转 | 通过（最大 0.0102 rad） |
| 完美闪避慢动作 | 通过 |

机器人试玩（`scripts/playtest.mjs`，真实按键、走完沉井上行地图，同样 60 秒）：

| 指标 | 0.8 基线 | 0.9 |
| --- | --- | --- |
| 每分钟击杀 | 15.4 | 22.8 |
| DPS | 142 | 216 |
| 最高连杀 | 7 | 18 |
| 平均击杀耗时 | 3.17s | 2.03s |
| 每次击杀破韧次数 | — | 1.3 |

对比前提：机器人不会平台跳跃，因此试玩脚本会让它传送到最近战斗；它衡量的是**同一场景下的战斗吞吐变化**，不是完整关卡通关能力。

## 六、复现

```powershell
npm run dev                     # 另开一个终端
node scripts/verify-feel.mjs    # 反馈层浏览器验收
node scripts/playtest.mjs 60 unlimited   # 机器人试玩指标
node scripts/playtest.mjs 60 unlimited mortal   # 不开无敌
```
