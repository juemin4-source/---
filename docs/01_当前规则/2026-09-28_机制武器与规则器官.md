# 2026-09-28 · 机制武器与规则器官

本轮设计修订：取消「少量改变动作或规则」的限制。规则改造成为器官核心方向，武器可以是空间、位移、部署与延迟结算系统。原始设计文本保留作为历史依据，以本轮会话决策修订其方向。

## 直接试玩

主菜单 → 无尽训练·无限槽 → B 配装台。新增六套预设排在列表前面，点击接入组合后继续战斗。**Z / X** 前后轮换主武器；1–9 保留旧武器直选。新武器同样可以从主武器下拉框选择。

## 六种武器

- 逆冲霰炮：七枚近距弹，真实水平后坐与向下射击的上升力。
- 磁钉枪：墙面和敌人作为锚点，相邻锚点形成伤害线，宿主远离时受牵制；锚点与线有生命周期。
- 捕鲸索：轻敌拉向玩家；精英或最大生命至少 250 的目标、墙面，将玩家拉向落点。牵引通过玩家碰撞物理，不传送穿墙。
- 回航刃：去程穿敌，回程变重击并清空命中集合；目标是玩家当前位置。到期、撞墙或抵达世界边缘都可启动回程，返程仍受地形阻挡。
- 坍缩囊：按住消耗体力，固定落点的泡膨胀至上限，吸入敌人、弹丸、掉落；松开坍缩。吸收的弹丸伤害参与爆发且有上限。实体墙阻挡投放、吸引和伤害。
- 裂隙刀：普通挥击留下 3.5 秒伤害线；新旧裂痕严格交叉触发一次爆发。需要改变位置/角度，原地重叠不反复爆炸。

## 十二种规则器官

完整名称与叠层说明在 `src/game/abilities/Content.ts`，配装台直接读取。

回程膜、镜胎眼、缝合索、迟发核、空泡肺、尸殖囊、寄生接口、偏折晶状体、逆极骨、蜕壳腺、裂生眼、移巢神经均已有实际效果。关键边界：

- 回程膜把普通弹丸的去程最长飞行时间限制为 0.55 秒再返回，新武器更短的去程保留；撞墙不是所有弹丸都能穿过去。
- 镜胎眼复制射击与近战，霰炮复制完整七发。复制威力 65%，复制和子弹后代不再次触发镜胎眼，部署物不会偷掉玩家残像。当前不复制重力泡、手雷投掷与部署指令。
- 迟发核把 35%～70% 直接伤害记在敌人身上。换武器后仍可由重击收债；卸下模块不抹掉已存债务，后续重击仍可结清。
- 空泡肺将现有 `blast` 爆炸延后 0.3 秒，先吸后推，兼容手雷、碎冰、范围重击与放电；结算阶段不会重新延迟自己。
- 缝合索传递水平反向力；逆极骨逐次交替推拉。不是完整绳索约束物理。
- 尸殖炮体会发射真实弹丸并能引发击杀连锁；最多 12 个，到期坏死。
- 寄生的炮台和无人机会随宿主移动；宿主死亡解除附着。移巢目前作用于已有炮台，因为游戏尚无玩家陷阱武器。
- 偏折晶状体识别自己的举盾位置和部署物，改向附近敌人并赋予重击；每枚弹只偏折一次。
- 蜕壳腺在受击耗尽护盾时发射穿透重击甲壳，自然衰减不触发。甲壳可被重力场处理。
- 裂生眼每次生成两枚 45% 威力后代，最多四代。每枚弹只分裂一次；每帧最多 48 个衍生弹、衍生时总弹丸上限 1200，防无限递归。

## 能力框架

- `AbilityEvents.ts`：有序事件与标签。攻击创建、命中、撞墙、到期、返程、重击、伤害前处理、击杀、冲刺、破盾、部署、击退、爆炸；事件可传递可修改的伤害与空间信息。
- `RuleModules.ts`：模块监听器；不按主武器 id 分支。回程膜只监听弹丸到期，镜胎眼只监听攻击创建，裂生眼只监听实体命中。
- `RuleAbilities.ts`：弹丸来源/代际、六武器机制、锚点/线/泡/尸殖/牵引的生命周期与绘制，以及兼容桥接。
- `Armory` / `SliceWorld`：保留原战斗流程，在明确边界发事件。原 30 器官的成熟实现仍走兼容路径，**没有宣称已将全部旧效果迁移到新框架**。角色回响目前也仍使用原有射击/挥击记录格式。

来源 root 与 generation 跟随复制、分裂；命中集合在返程时重置，生命周期结束释放实体。试玩 JSON 增加 `ruleAbilities`，包含事件次数、来源数量、最高代际、弹丸峰值和当前实体数量。

## 验证与未覆盖

新增 21 项测试：六武器行为、十二规则、旧手炮与狙击复用回程、镜胎近战与整次散射、部署物不抢残像、跨武器收债、有限递归、实际玩家位移、边界返程、六武器＋十二模块＋旧印记冻结链的交叉压力测试。

浏览器 `scripts/browser/rule-weapons-browser.js` 真实键鼠操作六种武器、Z/X 轮换与配装预设；捕鲸目标使用隔离重敌夹具。脚本不覆盖整趟探索制造成本，也不代表玩法已平衡。

本轮不扩展怪物生态。敌人尚未获得这十二种规则能力或六种新武器 AI；训练敌方武器选择仍只显示原五种，避免把不支持的行为假装成已实现。新器官优先作为玩家规则实验，通过固定遗留物和训练台获得。
