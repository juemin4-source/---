# 《永蚀》当前版本玩法设计

> 更新日期：2026-09-27。依据当前浏览器原型的实际实现，沿用原设计的章节结构整理。
>
> 本文区分三种状态：**当前规则**是已接入游戏的行为；**实验中**是已有实现、但效果与平衡尚未成立的部分；**后续设计**保留产品方向，不代表已经开发完成。文中数值只用于解释当前规则，不作为正式版定值。

## 1. 概述

### 1.1 一句话描述

《永蚀》是一款以固定大地图探索为载体的 2D 横版搜打撤动作游戏。玩家使用主、副武器猎杀携带器官的敌人，靠近吸收掉落的器官，在一趟探索中不断叠加能力、形成战斗组合，并决定继续深入还是携带收获撤离。

**当前版本重点已经落在“移动—战斗—吸收—组合变强”上。** 搜索、负重、撤离和怪物成长已有原型，但尚未组成稳定、有吸引力的完整局内循环；带回收获后推动角色、武器、设施成长的局外循环尚未完成。

完整产品仍希望做到：玩家带回蓝图、样本、人员和设备，获得新的武器改造、角色培养、研究与地图工程能力，使下一趟拥有更多选择。目前不能将这些写成玩家已经能够体验的内容。

### 1.2 设计目标

1. **好上手、有爽感。** 移动、跳跃、冲刺、攻击应及时响应，拾取和构筑不能频繁打断战斗。基础二段跳、靠近自动吸收与无限接入，是当前针对操作负担作出的调整。
2. **简单规则可以组合出深度。** 武器决定输出方式，器官改变动作、资源和状态之间的关系；空间、敌人能力与路线让组合有不同的应用场景。
3. **成长后仍然需要战斗。** 前期不能被怪物堵门压死，后期也不能只剩整屏秒杀。敌人应以组合、动作、位置和成长带来压力，而非单纯堆积血量。
4. **地图承载节奏。** 地图需要安排入门、交战、观察、紧张、恢复、奖励与回程。房间有自己的用途与空间关系，不能靠重复房间或密集梯子制造探索长度。
5. **长期变化来自局内和局外两端。** 这是产品目标，当前尚未验证。现有战斗系统能运行，不等于长期游玩已经成立。

### 1.3 当前循环与完整循环

当前最完整的一段：

**进入地图 → 移动与战斗 → 吸收器官 → 叠层与组合 → 使用更强的能力继续战斗。**

已有原型、仍需连接的一段：

**搜索具体物品 → 比较价值与负重 → 选择深入或回程 → 使用撤离点 → 成功结算 / 死亡损失。**

尚未完成的一段：

**带回物品 → 研究、武器改造、角色培养、设施建设 → 改变下一趟的准备和路线。**

原稿中的“击败 Boss → 返回”不再作为当前探索的必要流程。玩家可以不击杀高级怪直接撤离。成熟个体与 Apex 是探索中的危险和机会，不能等同于必须打败的关底门卫。

### 1.4 模式与范围

| 模式 | 当前用途 |
| --- | --- |
| 无限接入探索 | 主实验：固定地图中吸收不同器官，同类继续叠层 |
| 六槽探索 | 对照实验：保留器官种类取舍，用来比较构筑体验 |
| 无尽训练·无限槽 | 快速配置武器、器官和敌人，测试组合与持续战斗 |
| 无尽训练·六槽 | 在槽位限制下测试组合 |

训练场中的直接授予、配装与敌人配置是测试工具，不是局外解锁系统。训练场适合检查能力和平衡，不能替代正式地图对探索节奏与撤离决策的验证。

本文描述玩法规则和完成边界；不展开剧情、美术、正式工程架构与生产流程。

## 2. 核心战斗与构筑

### 2.1 基础动作

| 动作 | 当前规则 |
| --- | --- |
| 移动与瞄准 | 横向移动，鼠标瞄准；移动与攻击可结合 |
| 跳跃 | 基础二段跳；跳跃高度受输入影响，无需先取得器官 |
| 蹬墙 | 贴墙滑落、蹬墙起跳，可与空中跳跃连接 |
| 冲刺 / 闪避 | 冲刺提供位移和无敌窗口；实际躲过攻击可触发完美闪避反馈 |
| 下砸 | 空中按 F 发动，消耗体力；基础动作自带，坠星骨进一步强化 |
| 爬梯 | W / S 主动攀爬，跳跃、冲刺或攻击可脱离；重型货物限制此类通行 |
| 格挡 | 装备防卫盾后使用，消耗体力；普通格挡与完美格挡不同 |

动作能力是战斗基础。不能把普通移动、二段跳或基础下砸都锁在器官后面。地图中普通高度差应优先允许跳跃通过，梯子服务于确实需要的连接。

### 2.2 资源与状态

- **生命：** 归零后探索失败。本局吸收进度和部分器官能提高最大生命，这属于局内成长，不是角色永久等级。
- **体力：** 支付部分近战、防御和下砸动作，也参与满体力增益及眩晕回流。
- **热量：** 关联武器持续输出、过热停火和散热；高热可以成为收益条件，散热也可以转换成护盾。
- **充能：** 由撞墙、完美闪避等获得，通过放电髓强化重击。
- **护盾：** 承受伤害；可由散热或溢出治疗获得，也可被燃盾囊消耗以换取输出。
- **护甲：** 由复合甲壳提供，按比例减伤，不等同于护盾，也不是固定减去伤害。
- **敌方状态：** 包括印记、冻结、眩晕、易伤、破韧硬直等。不同状态有各自的施加、消耗和后续联动。

当前基础生命为 100；累计吸收每 6 层器官增加一档局内生命成长，每档增加 20 最大生命。厚生组织和回生膜另有生命加成，裂心瓣再施加生命代价。清掉器官不等于撤销已经累计的吸收进度，因此这几项不是同一种成长记录。

### 2.3 狂热、破韧与处决线

这三项是原稿没有充分覆盖的当前战斗规则。

**狂热：** 在连杀窗口内持续击杀可进入更高档位。当前四档门槛为 3 / 7 / 13 / 22 杀，提升攻速、移速、伤害和破韧能力；受伤会缩短维持时间。它鼓励主动进攻，也会与器官成长共同放大玩家强度，必须一起评估平衡。

**破韧：** 命中消耗敌人韧性，重击更擅长破韧。破韧会打断动作并产生可利用的硬直和易伤窗口；恢复与保护间隔用于避免无限压制。

**处决线：** 当前是对低生命敌人的直接伤害加成。敌人低于约 28% 生命时，符合条件的直接攻击获得额外伤害。它不是独立处决按键，也没有完整的抓取或处决演出流程。

命中顿帧、慢动作、镜头震动、后坐、受击闪光、粒子和尸体击飞共同反馈战斗结果。表现反馈不能代替敌人行为和数值上的挑战。

### 2.4 器官接入与叠层

当前共有 **30 种器官**：原有 28 种组合模块，加上厚生组织和复合甲壳。

1. 主实验不限制同时接入的器官种类，同种器官继续叠层。
2. 无限模式中，走近可拾取的器官会自动吸收，不需要逐个按 E；有代价的器官也会被自动接入。
3. 六槽模式保留种类限制，已装备的同类器官可自动叠层，新种类通过装备选择处理。
4. 配装面板可移除某种器官的全部层数。移除不等于禁止本局再次拾取。
5. “本局拒收 / 解除拒收”只有底层集合与拾取检查，尚未形成完整玩家操作流程；不能作为已完成机制描述。
6. 器官当前主要服务本局战斗。“吸收能力”与“封装成样本带回”之间的完整选择尚未接通。

#### 叠层不是所有效果无限线性增长

探索模式对部分强度效果采用递减收益：前两层按原层数计算，超过两层后，有效层数为 `2 + log2(实际层数 - 1)`。例如 5 层折算为 4 层强度，9 层折算为 5 层强度。

这个折算用于部分伤害、攻速、范围、治疗和连锁收益。**不是全部器官统一折算：** 部分计数、阈值、基础生命、护甲与代价仍使用实际层数。背包显示的层数也不会变成折算层数。训练模式保留较直接的叠层规则，因此训练场和探索的同层数表现不必完全一致。

#### 掉落与成长速度

当前探索已经压低普通敌人提供器官的频率：开局前三次玩家击杀各最多提供一个，之后普通幼体按击杀计数间隔提供；成熟个体最多提供两种、Apex 最多三种，每种一层。敌人自身拥有很多层，不代表死亡后全部转移给玩家。

敌人尸骸仍保留供生态使用的器官数据。玩家获得的掉落与怪物吞噬的尸骸是两个相关但不同的对象。

这些是抑制早期滚雪球的实验规则，不是平衡已经完成的结论。

### 2.5 器官能力母版

原稿的设计方法仍然保留，整理为五类：

1. **直接强化与代价强化：** 提高既有能力，或牺牲生命等条件换取更强输出。
2. **条件与操作奖励：** 在高热、满体力、空中等条件下增强；通过完美闪避、撞墙、眩晕获得资源。
3. **积累、消耗与转换：** 积攒充能后重击释放，散热转护盾，溢出治疗转护盾。
4. **状态与连锁：** 施加印记和冻结，再通过传导、传播、碎冰继续产生效果。
5. **动作改造：** 冲刺获得撞击、下砸按高度增强、空中击杀获得额外跳跃机会。

能力领域仍围绕动作、参数、资源、状态和空间。燃烧、流血、中毒、寄生等可以保留为扩展词汇，但不能列入当前已实现状态。

### 2.7 武器

当前为 **5 种主武器 + 4 种副武器**，同时选择一主一副。原型允许切换和测试，不要求先通过局外制造解锁。

| 武器 | 当前动作规则 | 与原稿的重要区别 |
| --- | --- | --- |
| HCP-05 连续射击手炮 | 可按住持续射击，每第五发为重击 | 不必连续点按维持输出 |
| AR-H7 热负荷自动步枪 | 按住连续射击，高热时形成重击；过热后需冷却 | 已接入热量输出窗口 |
| SR-P3 贯穿狙击枪 | 按住蓄力、松开射击；短按为普通弹，达到蓄力门槛为贯穿重击 | 核心是释放时射击与贯穿，不把范围爆炸写成基础能力 |
| CQC-R4 节律匕首 | 按指定节拍点按，成功积累伤害增益，无重击 | 每层约 20%，最多 15 层；节奏错误扣三层，而非全部清空 |
| HM-03 重锤 | 三段攻击，第三段为范围重击 | 可持续输入衔接，受体力与连段时限约束 |
| DS-60 复合防卫盾 | 持续格挡消耗体力；正面普通格挡减伤，举盾初段可完美格挡 | 完美格挡不等于已经有通用反弹飞行物能力 |
| IG-02 冲击手雷 | 蓄力后投出，爆炸以击退为主要价值，也有基础伤害 | 是空间控制工具，不只是高伤爆炸 |
| UAV-08 伴随作战无人机 | 部署跟随作战单位，最多同时三架，本局库存八架，可被摧毁 | 库存与场上数量分别限制 |
| SGT-01 自动哨戒炮塔 | 部署一座自动攻击炮台，再次部署替换旧炮台，可被摧毁 | 强调驻守与位置选择 |

“重击”是攻击的性质，不是所有武器共有的独立按键。匕首没有重击，因此不能自然使用依赖重击的全部组合。这种武器与器官之间的适配关系应保留。

原稿中的模式切换、更多投射器、弓弩、屏障和领域属于后续武器设计空间，不计入现有九件武器。

## 3. 角色系统

### 3.1 当前角色结构

当前玩家使用一套主要角色操作与战斗框架。构筑差异主要由主副武器、器官组合、叠层以及局内战斗状态提供。

已有角色基础项包括生命、体力、移动与跳跃、攻速、热量与散热、充能、护盾等；这些属性受到武器、器官和狂热影响。当前没有完成可选择的多角色技能体系，也没有完成角色永久养成树。

### 3.2 保留的角色方向（后续设计）

七曜仍可作为角色能力设计的分类方法：

| 方向 | 能力主题 |
| --- | --- |
| 日 | 峰值、热量、充能、强输出窗口 |
| 月 | 回响、散热、重复、延迟触发 |
| 金 | 破防、切断、解除、牺牲与转换 |
| 木 | 生长、召唤、复制、逐步成长 |
| 水 | 位移、传播、领域、目标间转移 |
| 火 | 连锁、连续触发、爆发扩大 |
| 土 | 储存、阵地、积累与延迟兑现 |

原稿中的主角记录与重放有效动作、房日兔过热继续输出、程岳临时作战单位、乔鸢短时提速、陆衡防御区域、杜宽月印延迟恢复，均保留为角色技能候选，**不列为当前玩家已拥有的技能**。其中记录与重放仍需单独明确哪些事件可以复制、如何支付资源、如何避免递归。

### 3.3 长期培养（后续设计）

保留通过技能强化、互斥分支、养成点与特训拓展角色的方向。养成重点是新增打法与接口，同时可以调整性能、持续时间、次数和冷却。

目前没有完成金币与特训券投入、技能行为任务、互斥养成树或多角色成长。局内因吸收器官而增加生命，不能替代这一系统。完整局外培养、投入与继承规则见第 4 章。

## 4. 局外养成与据点循环

> 本章保留现有结算事实，并补充完整产品的局外设计。除 4.1 外，以下均为待实现设计；新增的具体规则作为本轮设计提案，数值与分支内容仍需验证。

### 4.1 当前实现边界

成功撤离会累计本次收益，并记录带出时身上的器官种类作为研究档案；死亡不获得该次撤离收益。已有出行次数和部分旧捷径标志等存档字段。

当前档案主要是收集记录，累计收益主要是结算记录，尚无完整的物品仓库、售卖、制造、角色培养、设施建设与资源消耗链。原型还混有击杀收益等旧的抽象收益来源，尚未全部转为具体物品经济。

存档中的捷径字段不代表地图设施已经全面实现永久建设。现有供电与货运连接首先服务本趟探索。

### 4.2 局外养成的目标与循环

玩家每趟带回的东西应对应一个可理解的长期用途：救回的人让据点能做新的事，书籍传授知识，设备提高生产能力，器官样本带来武器结构研究，金币支持训练与日常投入。

完整循环为：

**确定本趟目标 → 选择角色、武器与补给 → 探索并带回收获 → 存储、出售或投入研究建设 → 获得能力或路线选择 → 带着新的计划再次出发。**

局外成长同时提供两种回报：有限的基础能力提升，以及武器、技能、设施和路线的新选择。永久属性增幅需要有边界，避免养成到后期把地图与局内器官构筑变成无意义流程。

玩家不必每次回城都操作所有设施。结算后能直接看到本趟收获推进了哪些目标，也能暂存物资立即再次出发。

### 4.3 结算、仓库与资源去向

成功撤离后，携带的具体物品进入据点仓库，按玩家选择出售、拆解、研究或投入建设。物品价值只是售卖参考；稀缺用途不能被一个总价值数字掩盖。

| 带回内容 | 可选用途 | 对下一趟的影响 |
| --- | --- | --- |
| 普通零件、设备 | 留存、出售、拆解或建设投入 | 支付制造与补给成本 |
| 器官样本、蓝图 | 研究结构、解锁改造、出售重复物 | 改变武器选择和使用方式 |
| 书籍、技术资料 | 学习、研究前置、收藏重复资料 | 解锁职业能力或工程知识 |
| 人员 | 安置、学习、分配适合的工作 | 开办或扩展设施服务 |
| 大型设备 | 安装到设施、保留备用或出售 | 解锁新的制造与工程能力 |
| 星骸等一次性物品 | 完成固定探索收集或特定永久解锁 | 具体用途另行设计，不直接作为通用货币 |

不得自动出售尚有研究、学习或建设用途的稀有物品。仓库显示物品对应的已知用途；玩家可以为研究或建设目标预留材料。

探索死亡损失未带出的物品和本局临时器官。已完成的研究、角色培养和设施建设保留。第一版不额外加入角色永久死亡或已解锁武器永久丢失；这些惩罚如需引入，应单独评估。

### 4.4 经济系统

**金币**是通用流动资源，主要来自出售带出的战利品；未来可扩展委托和据点活动。用途包括商店购买、人员雇佣、角色特训、武器制造与设施升级。

**工程材料**来自具体物品的拆解或提炼。例如电池提供锂相关材料，电机提供机械部件。地图尽量掉落有来源、有用途的物品，据点负责将其加工成所需资源。

**超重氢等特殊资源**服务大型能源设施、永久地图工程及关键制造，不与金币完全互相替代。

**特训券**与金币共同用于角色训练。获取渠道、训练时间和消耗量待定，不能在没有稳定来源时把它设为早期成长的硬门槛。

资源关系保持易懂：通用费用用金币，工程能力需要设备和材料，知识能力需要人员与资料。第一版不扩张大量用途重叠的货币。

### 4.5 战斗角色培养

角色不采用一个包办所有成长的总等级。玩家通过特训获得养成点，投入该角色的能力树；树的阶段可以表示培养进度。

角色成长包含：

1. **基础能力：** 有限提升生命、体力、散热、攻速等身体性能，保证投入有感，同时保留局内成长空间。
2. **技能性能：** 调整持续时间、次数、冷却和作用范围。
3. **技能接口：** 强化技能与武器、器官、热量、充能和状态之间的关系。
4. **规则分支：** 高阶段解锁不同使用方式，改变打法，而不只是重复提高伤害。

七曜作为树的能力主题，不要求每名角色都拥有七条完整培养线。每名角色围绕自身技能选择重点，避免不同角色只换名字却使用同一棵树。

关键节点采用互斥分叉：选择一种特性后，其他方向暂时关闭。例如召唤方向可在“单体强单位”“多单位协同”“短时集中爆发”之间取舍。此例用于说明分支形式，不代表程岳技能树已经定稿。

第一版建议允许在据点重置分支，以支持试验；不在局内随时切树。重置费用另定，不应高到阻止玩家尝试新构筑。

技能升级结合角色自身行为条件，例如使用防御技能成功保护、利用回响完成有效连锁等；不统一套用“击杀同样数量敌人”。行为条件用于引导理解技能，不应迫使玩家反复进行与正常玩法冲突的刷取。

局外培养永久保留；本局器官层数、吸收带来的生命成长、狂热与战斗资源在新一趟重新建立。

### 4.6 武器获取、研究与改造

正式循环中，玩家通过发现蓝图、研究样本以及获得相应人员和设备，解锁武器制造与改造。当前原型九件武器自由切换仍属于测试入口，不能当作这套获取流程已经完成。

武器成长分为三层：

- **武器解锁：** 获得一种新的基础动作与输出方式。
- **有限强化：** 改善基础性能，明确上限和成本。
- **结构改造：** 从器官研究中获得可选择的武器接口，改变使用方式。

器官样本的研究结果是结构原理，不是把器官所有层数永久复制进武器。比如压电类研究可以提出与撞击、充能有关的改造方向，但不应一次研究就永久附送完整的撞墙放电组合。

同一武器的关键改造应有选择或代价，避免所有研究成果最终无条件叠在一起。改造数量和具体互斥规则待武器专项设计确定。

完整链条为：

**获得完整样本或蓝图 → 带回 → 满足人员、设备与知识前置 → 投入资源研究 → 永久解锁方案 → 制造或安装改造 → 下一趟使用。**

已吸收入身体的器官与完整研究样本需区分。当前“撤离时记录已装备器官”的档案机制不自动等价于获得完整样本。未来吸收 / 封装交互需要低摩擦地解决，不能为局外研究牺牲现在的自动拾取体验。

### 4.7 人员、书籍与职业

地图可遇到不同年龄、背景与专业的幸存者，包括机械师、医生、工程师、科学家以及尚无专业的居民。救回后先安置，再根据能力和意愿用途分配设施岗位。救援过程、跟随方式与撤离条件需要独立设计，目前尚未实现。

知识可通过书籍和资料获得：

**普通居民 + 对应书籍 + 学习条件与时间 → 获得知识 → 达到职业要求 → 提供设施能力。**

例如《机械维修基础》可以支持维修知识培养；高级工程职业可要求多本资料、前置知识与可使用的设备。一本入门书不会立即把居民变为顶级专家。

书籍的价值是解锁知识方向，人员提供执行能力，设备提供实际生产条件，三者共同构成据点成长。学习与训练的时间推进方式待定，第一版优先避免强制现实时间等待。

### 4.8 设施与升级条件

| 设施 | 主要作用 | 主要成长来源 |
| --- | --- | --- |
| 商店 | 补给、通用物资交易；未来扩展雇佣 | 人员与供应能力 |
| 研究站 / 工坊 | 样本研究、武器制造、改造安装 | 科研或机械人员、蓝图、机床 |
| 矿物提炼设施 | 将具体物品加工为工程材料 | 技术人员、处理设备、能源 |
| 发电站 | 支持大型设施和工程 | 发电设备、能源材料、维护人员 |
| 运输站 | 货运能力与地图运输工程 | 运输设备、工程知识、供电 |
| 居住区 | 安置获救人员，支持人口扩张 | 居住条件与基础设施 |
| 特训营 | 角色训练、养成点与能力培养 | 教学条件、人员、金币与特训资源 |

设施成长以能力变化为节点，避免只写“一级到二级效率提高”。例如：

**救回机械师 → 建立小工坊 → 带回机床与技术资料 → 开放新的加工类别 → 增加技师与工业机器人 → 扩展制造能力。**

大型货物因此有明确的长期诱因：玩家搬运的是某项具体能力的缺失设备。出发前可以知道自己缺什么、可能在哪里找到，以及带回后有什么用。

### 4.9 永久地图工程

运输、供电与工程设施未来可以支持固定地图的永久改造，例如修复运输连接或启用特定设施。永久工程改变下一趟的选择，成果应明确可见并保存在据点进度中。

必须区分三类状态：原本固定的地图结构、本趟开启的门或电源、跨局完成的永久工程。普通交互不能无意间全部变成永久解锁，永久工程也不应消除所有探索风险。

当前地图的供电与捷径先按已有局内规则运行；哪些连接成为永久工程，需要逐项确定。

### 4.10 出发准备与继承边界

出发时选择角色、已解锁的主副武器及改造，准备适量补给，并可标记本趟的收集目标。目标提示服务探索，不强迫玩家按任务箭头走唯一路线。

| 保留到下一趟 | 每趟重新建立 |
| --- | --- |
| 角色已完成的培养与技能解锁 | 本局吸收的器官种类与层数 |
| 武器解锁、研究成果和已拥有的改造 | 局内吸收带来的身体成长 |
| 据点仓库、人员、知识和设施 | 狂热、临时状态与战斗资源 |
| 明确完成的永久地图工程 | 当前局的货物、敌人生态与临时开关 |

局外提供起点与方向，局内仍然需要获得器官、形成组合和判断何时撤离。不能默认继承上一局的完整构筑，无论当前选择无限接入还是六槽对照模式。

### 4.11 第一阶段可交付闭环

完整局外设计不要求一次开发所有设施。第一阶段先实现一条能实际玩通的成长链：

1. 搜索并带回一件有明确用途的物品。
2. 物品进入仓库，可选择保留、出售或投入目标。
3. 在一个基础工坊中完成一项研究或武器改造。
4. 下一趟能装备该成果，并看出打法的变化。
5. 同时提供一条有上限的基础角色训练，让结算收益具备稳定用途。

随后再接人员与书籍前置、大型设备升级、更多角色分支和永久地图工程。验收应实际走通“带回—投入—成长—再出发”，不能只展示设施页面与进度条。


## 5. 地图、生态与搜打撤

### 5.1 地图结构与节奏

当前探索使用固定手工布局，整体从低处向上推进，包含九个命名区域：南侧气闸、废弃维修工区、排水观察廊、滤水维修环、仓储与货运站、九号泵机大厅、背泵值班室、上层控制与封存区、东侧设备吊装间。

空间通过实体楼板、墙体、洞口、跳台、有限梯子、捷径与货运连接组织。学习地图应帮助玩家判断哪里能走、怎样回程以及负重后哪些路会失效。

地图设计继续遵守：

1. 先安排体验，再安排房间形状。每个区域明确承担交战、观察、奖励、缓冲或路线选择中的什么作用。
2. 保持迷宫式连接与局部遮挡，避免大面积开阔平台让全图变成同一个战场。
3. 普通落差优先用跳跃解决，梯子不承担大部分移动时间。
4. 搜索点、生态活动和回程路线相互影响；有价值的房间不只是末端摆一个箱子。
5. 同一条路线去程与负重回程应有差异，但不能靠无法识别的通行限制惩罚玩家。

这些是地图评判标准，不代表当前布局已经全部满足。地图已经固定，也不等于房间节奏和路线选择已经设计完成。

### 5.2 怪物生态（实验中）

当前生态由巢穴、个体、尸骸和区域关系组成，个体具有身份、来源、生物量、器官组合和成长阶段。

- **拾荒者：** 较弱，寻找尸骸，是捕食关系中的弱势单位。
- **猎手：** 可攻击玩家，也会捕猎符合条件的异巢弱小个体。
- **浮游单位：** 形成远程威胁，移动和战斗方式区别于地面单位。

敌人可以携带多个器官及同类层数，部分武器与器官效果已经用于敌方战斗。敌人能力与玩家能力有对应关系，但没有实现全部 30 种器官的完全镜像；怪物互斗也没有覆盖所有武器组合的完整战斗演算。

#### 尸骸、进食与成长

死亡产生独立尸骸数据，保存位置、生物量、器官与存续时间。怪物寻找可接近的尸骸，移动、进食，获得生物量并继承部分器官；尸骸会过期。玩家附近的实际追击与战斗会影响进食机会。

个体按生物量从幼体成长为成熟个体，再成为 Apex。当前阈值分别为 12 和 34。成熟个体以精英身份呈现；成长增加生命、韧性、能力容量和活动范围，生命增长采用有限档位，而非随时间无限倍增。

Apex 可以从普通个体成长出来，不要求在固定分钟凭空生成，也不要求每局必定出现。成长机制存在，不等于玩家已经能稳定看见、理解并利用这一过程。

#### 离屏活动与再繁殖

玩家附近运行实体移动、捕猎和进食；远处使用低频抽象生态更新，继续处理繁殖、捕食、吞噬、成长与迁移。巢穴有局部繁殖限制和全局数量控制，并避免贴着玩家立即补怪。

两种模拟的精度不同。当前远场捕食不是逐次攻击动画，区域迁移也不是完整的地形寻路。不能据此描述为所有怪物都能沿玩家可走的每条楼梯自主跨区追猎。

#### Threat 的含义

生态威胁是对存活个体、生物量、器官、成熟 / Apex 数量等的摘要，不是给全体怪物乘伤害或生命的统一难度旋钮。

玩家应在正常游戏中看见捕猎、吞噬、成长与路线变化。F3 调试信息和日志用于追溯原因，不能替代这些场内表现。目前生态的可见性、发生频率及对玩家决策的影响仍是重点问题。

### 5.3 搜索与地图资源

普通器官掉落与容器搜索采用不同交互：**器官靠近吸收；搜索点按住 E 完成搜索。** 搜索耗时并产生噪音，噪音可影响附近敌人的行为。松开、受击、攻击或离开有效条件会中断；当前中断清空搜索进度，并非保留部分进度。

当前配置了 14 个固定搜索点，包含具体物品、重量、占用容量、价值和来源；部分附加内容随种子变化。

| 原稿资源 | 当前状态与调整 |
| --- | --- |
| 金币 | 当前有累计收益记录，没有完整商店与售卖货币循环 |
| 吞财宝的 AI 宝箱怪 | 未完成；普通搜索点不能视作已经实现这种怪物机制 |
| 具体材料 / 设备 | 已有淤积样本、冷凝剂罐、生物部件等具体物品；提炼链未完成 |
| 人员 | 救援、带回、职业与人口用途未完成 |
| 书籍 | 已有泵站维修手册作为战利品；学习与职业解锁未完成 |
| 蓝图 | 已有锻造蓝图物品；研究与武器改造未完成 |
| 大型物资 | 已有回生罐、感应脊柱、反应堆芯，具有负重与路线影响 |
| 星骸等一次性收集物 | 保留设计方向，未完成永久收集系统 |
| 器官样本封装 | 尚无完整的吸收 / 封装二选一流程 |

### 5.4 负重与大型物资

货物按容量整理，当前容量为 6 个单位，各物品占用不同。**货物容量与器官槽位是两个系统；无限接入不等于无限货物背包。**

负重影响移动，重型物资还降低跳跃和冲刺能力，限制攀梯、蹬墙以及特定狭窄通道。物资可丢下留在地图中，再取回。

这里需要形成的决策是：带走哪件东西、是否先放下打架、是否放弃原路线，以及为了货物多承担多少风险。减速效果已经存在，完整的有趣搬运体验仍需结合地图验证。

### 5.5 撤离与失败

- 初始气闸无需击杀 Boss 或 Apex 即可使用，但当前不接受重型货物。
- 货运撤离需要恢复供电，可以处理重型货物。
- 撤离需要持续交互，移动、攻击或受到伤害会中断。
- 撤离危险原则上来自现存世界活动，不靠临时生成固定防守波完成流程。
- 成功撤离结算收益；死亡丢失本局未带回的货物和临时构筑，已保存的累计进度保留。

当前“有撤离按钮”和“有收益差异”已经成立；是否真的让玩家产生贪心、犹豫、回程事故和主动收手，仍未得到充分验证。

### 5.6 固定与变化

| 固定部分 | 本局可变化部分 |
| --- | --- |
| 主地形、房间连接、重要地标 | 普通个体的位置与活动 |
| 搜索点位置、关键设施、撤离点 | 繁殖、死亡、尸骸与吞噬结果 |
| 捷径位置与开启条件 | 敌人器官组合与成长阶段 |
| 主要货物来源与区域用途 | 部分战利品内容、当时的路线风险 |

原稿“Boss 位置固定”不再概括当前生态高级怪：成熟个体与 Apex 有来源和成长过程，不能全部固定为房间摆件。将来仍可另设固定特殊敌人，但需要单独设计。

“人员刷新”“永久星骸消失”“地图工程永久保留”等仍属于未来固定地图循环的扩展，不能与当前每局变化混写。

## 6. 当前完成边界与下一阶段问题

| 部分 | 当前结论 |
| --- | --- |
| 操作与战斗 | 已有较完整的动作、九件武器、资源状态、打击反馈与战斗组合，可继续打磨 |
| 器官构筑 | 无限接入、叠层、30 种能力、局内生命成长已接入；掉落与滚雪球仍需平衡 |
| 敌人生态 | 有真实个体、尸骸、吞噬、捕食、成长和远场更新；玩家可感知程度与行为完整性仍不足 |
| 搜索与搬运 | 有持续搜索、物品、容量、负重和通行限制；风险收益与空间结合仍在实验 |
| 局内搜打撤 | 有必要部件，尚不能宣布完整体验已经成立 |
| 局外养成 | 目前主要是结算和档案骨架，角色、研究、设施与经济循环未完成 |

接下来最值得验证的是三件事：

1. **持续有压力的战斗成长。** 同时观察开局生存、器官获取速度、狂热叠加和中后期敌人的实际存活时间，避免在“堵门秒人”和“清空无敌”之间来回摆动。
2. **可见且影响路线的生态。** 玩家在正常探索中能看见怪物吞噬和成长，能理解某只精英为何出现，并因此改变交战或回程选择。
3. **一次值得主动撤离的收获。** 先让搜索、货物价值、负重回程和结算形成有意义的小循环，再接上一个真实的局外用途。不能用增加更多模块代替闭环。

程序测试能够证明规则在特定条件下发生，不能证明游戏已经好玩。当前文档记录实现事实与下一步需要回答的问题，不将原稿愿景包装成完成状态。
