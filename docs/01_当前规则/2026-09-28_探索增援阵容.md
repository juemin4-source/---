# 探索增援阵容

探索新增援按出生时间取得配置，旧怪不会随时钟突然变强。训练场原有波次规则保留。

| 时间 | 后续出生阵容 |
| --- | --- |
| 0–2 分钟 | 保留原有追猎、射手、近战居民配置 |
| 2–4 分钟 | 加入盾卫、狙击与冲锋专职配置 |
| 4–8 分钟 | 加入布雷、维修者，精英至少三种器官 |
| 8 分钟以后 | 第五档封顶，不无限指数膨胀 |

每档出生基础生命增加 22%，伤害增加 10%；最高为基础生命 1.88 倍、伤害 1.4 倍。生态阶段与器官仍分别生效。职责按区域和个体编号分配，种子复现不变。沿用巢穴位置、人口上限、附近抑制与 280 像素禁刷距离，没有新增撤离防守波。没有提高完整器官掉落预算。

- 追猎：匕首近战。
- 射手：手炮。
- 冲锋：重锤及冲撞器官，后期接撞墙充能与放电。
- 盾卫：重锤与正面盾牌，侧后方绕行可避开正面减伤。
- 狙击：贯穿重击，蓄势时显示瞄准线。
- 布雷：手炮并在自身脚下布雷，每人最多三枚，全场最多十八枚；0.8 秒布防，接近触发后 0.7 秒预警，14 秒失效，主人死亡清除。
- 维修：步枪，每六秒治疗附近有视线的最多三个其他敌人，每次不超过 24 生命或目标最大生命的 8%。

当前复用原有身体，增加职责文字、盾板、冲锋角、维修十字和地雷预警。尚未为七种职责制作独立完整动画资产。时间阵容是本轮的直接战斗压力来源，不宣称已经完成生态重做或最终平衡。
