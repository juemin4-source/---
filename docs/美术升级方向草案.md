# 永蚀 Demo 美术规范 · 方向 02

依据：用户提供的 Demo 美术风格说明与主角设计图。本规范替代上一版方向；第一轮可玩样板已接入，进度与限制见 art/可玩美术样板_01.md。概念图不是引擎截图或可直接导入的素材。

## 总原则

偏二次元的 2D 横版动作美术。干净、克制、易读，清晰轮廓，赛璐璐式受控光影。优先服务主角打怪、动作识别与敌人辨识度。

世界主题为“人类残存地下设施 + 神遗留机械生态入侵”。维修区、仓储区、管道、电梯井、工业设备和应急照明有明确工程逻辑；异质体系对其侵蚀、覆盖、寄生和异化。

避免写实、过重 3D 渲染、脏乱噪杂、强 HDR、普通霓虹赛博朋克或传统机甲科幻。先前的肉质器官生态方案不再作为方向。

## 主角以用户设计为准

参考：`art/主角设计_用户参考.png`。

- 清楚的人形轮廓，银白长发、绯红眼睛与发饰，黑白服装、绯红内衬和飘带，腰部交叉带与不对称腿部设计。
- 不再采用兔形或匿名面罩猎人方案。
- 游戏尺寸下优先保留白发大色块、服装黑白分区和红色点缀。纽扣、带扣和碎发可以简化。
- 头发、衣摆用大束、大块面作跟随动画，不遮住持械手、膝盖、脚和受击位置。
- 身体与武器分层。待机、跑动、起跳、二段跳、下落、冲刺、下砸、落地和受击需要明确姿态差异。
- 外观与碰撞盒分别管理，长发和衣摆不扩大受击范围；左右不对称以原图为准，不能直接把概念图当作标准转面。

## 两类机械敌人

| 维度 | 人类科技机械怪 | 神造太空科技机械怪 |
| --- | --- | --- |
| 来源 | 维修、工程、运输、安保设施失控 | 异质技术生命，神性、深空与海生感 |
| 轮廓 | 方块、直线、折线，重心稳定 | 环状、放射状、悬浮部件，弱方向性 |
| 构造 | 明确前后上下，机械臂、履带、足部、夹具、炮口、传感器 | 核心、分瓣外壳、轨道、机械触须、漂浮附件，无需头脸 |
| 运动 | 承重、支撑、关节转动与后坐力 | 漂移、脉冲、旋转和径向展开 |
| 前摇建议 | 支撑脚固定、炮口对准、机械臂收紧 | 环体锁定、部件收拢、核心聚光、轨道变形 |

神造机械参考水母、头足类、珊瑚、海百合的结构与运动，但本质必须是机械/神造科技，不能变成肉质生物。两类敌人不能只靠换颜色区分。

“器官模块”可保留为玩法术语，视觉上解释为功能单元：冻结核心、压电组件、刻印传感器等。外形、攻击动作与掉落图标保持对应，此处不改动玩法规则。

## 场景、光色与特效

背景审美与落地细则见 [背景感受参考与落地要求](art/背景感受参考与落地要求.md)。视差本身不等于景深；须同时建立近远尺度、明度与边缘差异、遮挡关系和有来源的光。

- 场景按前景、战斗层、远景拆分。远景低对比，前景遮挡集中边缘，平台顶面和交互物清晰。
- 材质以大色块和少量阴影表达；旧化只说明局部损坏，不平均铺满纹理。
- 人类区域通过工程秩序体现来源；异质入侵通过异常轨道、机械附着、漂浮结构和结构替换体现。
- 主角白发与黑白红配色为第一视觉锚点。实施建议：人类设备低饱和工业黄、灰金属；神造设备冷灰壳体与少量青紫能量。
- 危险提示必须有形状和时间变化，不单靠颜色；背景灯不能模仿攻击提示。
- 特效有蓄势、释放、消散层次。限制高构筑下的粒子、闪白和震屏，确保敌人前摇与地形可见。
- 宝箱、模块掉落、开关有稳定外形和交互标志。UI 不遮挡脚下平台与敌人动作。

## 第一段可玩样板

范围：沉井入口、两侧检修梯、首场战斗、一个分支奖励。先制作主角一套动作、一个工业机械敌人、一个神造机械敌人、三种功能模块、一个宝箱、一组分层场景。

顺序：实际游戏尺寸和灰度剪影 → 敌人轮廓与前摇 → 场景分层 → 动作和武器 → 特效 → UI。生成概念图用于选方向，实际素材还需拆层、清理边缘、统一尺寸与落脚点，再接入动画和碰撞。

验收：关闭文字仍能区分主角/敌人/背景和两类机械；缩小画面仍能看清持械手与脚；高强度战斗可辨前摇；装饰不误导碰撞边界；跑跳、二段跳和下砸路线回归通过。
