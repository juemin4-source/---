## 对当前样板的诊断

当前代码场景虽有视差，但仍主要是重复矩形、等间距管线与重复灯具。各层的明度、锐度、尺度差异不足；缺少一眼记得住的场景焦点和亮暗节奏。因此“图层在动”还没有充分转化为“空间很深”。

下一轮背景工作的优先顺序应是构图、明度与光源结构，之后才是材质和装饰数量。

## 一屏沉井入口的目标构图

1. 主角所在的战斗层：脚下平台顶面清晰、角色周围留有低细节区域，补给柜与气闸门是可识别的功能物。
2. 中景：一侧保留维修间的完整结构，另一侧露出被神造机械侵占的井壁，形成非对称构图。
3. 远景：竖井与跨井机械桥逐渐隐入水汽；尺度比战斗层设备大，描边和局部对比更弱。
4. 主光源：上方远处破口或井口投下冷光，说明“向上”的空间方向；气闸门局部暖光表示人类设施仍在工作。
5. 前景：侧边少量深色管道和下沿积水或遮挡，只负责建立框景，不遮住脚、落点、敌人或弹道。
6. 神造入侵：利用悬浮环体、异常结构替换和少量脉冲能量形成次级焦点，亮度不与玩家及危险提示竞争。

此构图是落地目标，不意味着新增可站平台、门或改变关卡路线。背景中的桥和管线必须和战斗层的平台有明确视觉区别。

## 分层要求

- 远光/空气层：宽而柔和的色调变化，少细节，不使用全屏强 HDR。
- 远景巨构层：大形、低对比、低饱和、弱边缘；低速视差。
- 中景设施层：说明房间用途、构件连接和机械生态来源；中等对比与视差。
- 战斗层：最明确的落脚边缘与攻击关系；装饰细节为动作留空间。
- 前景框景层：局部最深的色块；如果使用虚化，只限于非交互前景，不能虚化危险信息。
- 光源与空气效果跨层协调：光束有来源和遮挡逻辑；不要用一张半透明雾图均匀盖住全部层。

## A06 背景制作顺序与验收

- [ ] 先出同一屏的三个灰度构图小稿，仅比较主次、留白、尺度与上下方向。
- [ ] 选出一个构图后做主光与辅光色稿，说明光从哪里来、照到哪里。
- [ ] 带入实际尺寸主角、工业机械和神造机械，检查剪影是否清晰。
- [ ] 拆分视差层接入游戏，检查移动时接缝、露底、漂移和遮挡。
- [ ] 将原碰撞与平台位置叠加检查，背景装饰不能误导跳跃。
- [ ] 最后添加材质、少量水汽、反光与场景动态；不靠增加噪点制造“丰富”。

验收问题：第一眼看向哪里？哪里可走/可站？是否能感到远处还有空间？明暗变化是否有来源？玩家奔跑、二段跳和敌群交火时，这些关系是否仍然成立？

关掉粒子与 UI 后场景仍须有构图和层次；开回战斗效果后不能失去清晰度。灰度、缩小窗口和连续滚屏都要检查。
