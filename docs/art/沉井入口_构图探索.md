# 沉井入口 · 构图探索 01

用户暂时搁置角色动画后，转入 A06 背景前期设计。仅探索构图，不代表跳过角色验收，也没有改变地图、平台或碰撞。

图稿：`沉井入口_灰度构图_01.png`。内置 image_gen 生成，三幅从上到下分别为 A、B、C；提示词见同名 prompt 文件。此图是概念，不是实机背景资源。

| 方案 | 优点 | 待解决 |
| --- | --- | --- |
| A 开阔巨井 | 巨构尺度与顶部光源明确；角色附近留白充足 | 上行可探索结构弱，底部横向长走廊感明显 |
| B 维修设施剖面 | 多层房间、服务梯和井道有空间逻辑，适合纵向探索 | 左右过于对称，中央地标还不够独特 |
| C 神造入侵 | 前景框景强，放射状机械与人类设施形成来源区分 | 气氛强于可玩结构，异质圆环仍比较泛化 |

建议以 B 的剖面空间为基础，打破左右对称，引入 C 右侧少量神造机械和 A 的远景尺度。下一张色稿明确左侧暖气闸、右侧冷井壁、顶部远光；不均匀铺满灯光。

本轮发现的尺度限制：生成稿中的人物小于实际游戏的屏占比，不能直接作为角色可读性验收。进入色稿时必须按 1280×720 视口、约 54px 主角高度重新检查。生成图带有纵深透视；真正可碰撞的平台仍要严格侧视，不能把远景桥误当落脚点。

后续顺序：选定构图→光色稿→实际尺寸角色/敌人叠放→分层背景制作→对齐现有碰撞后接入。当前不修改游戏背景代码。
