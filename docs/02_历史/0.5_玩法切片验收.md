# 器官猎场 0.5 · 验收与试玩

> 历史版本 0.5。当前模块、武器、训练规则以 [0.6 扩展说明](无尽训练场与武器验证_0.6.md) 为准；本文保留首轮记录。

日期：2026-09-22。

## 启动与产物

```powershell
npm run dev
```

打开终端给出的本地地址；本次使用 `http://127.0.0.1:5173/`。

- 默认：新的器官猎场。
- `?legacy`：保留旧版房宿灰盒。
- `?combat`：保留旧五房战斗测试场。
- `npm run build`：类型检查与静态构建；产物为 `dist/`。
- `npm test`：当前项目测试；`npm run test:slice`：只检查新切片。

## 本轮修复的实际问题

1. 旧 `ExpeditionUI.ts` 的器官耐久提示引用了作用域外的 `m`，造成 TypeScript 构建失败。改为当前 `nearest` 器官。
2. 新模式装配／开始后，缓存的空面板状态可能让旧面板继续遮住鼠标。将可见性更新放在缓存判断之前，并加入浏览器回归检查。
3. 原始近身接触伤害绕开了蓄力预警。新模式中近战伤害只出现在明确的冲锋窗口。
4. 重复器官落在门口可能阻碍撤退。站在门正前方时优先通行；要取旁边器官可根据地面的 E 提示稍微调整站位。
5. 高刷新率下跳跃／冲刺的单次输入可能早于固定更新帧，被下一渲染帧覆盖。将输入缓存到实际模拟步消费。
6. 关闭面板重置鼠标按键时保留瞄准坐标，避免瞄准突然跳到左上角。
7. Vite 忽略 `dist/`，避免在开发服务器运行期间生产构建写入 HTML 引发整页重载、中断当前出行。
8. 测试范围限定为当前 `tests/`，避免把 `output/` 内历史归档测试混入当前结果。

已完成的浏览器结果：

- 普通键鼠完整路线：气闸 → 采掘场 → 锻造井 → 枢纽 → 共鸣室 → 培养廊 → 气闸，成功结算 **590 样本**，击杀 **16**，解锁运输捷径。出行模拟时间约 **63 秒**，装配面板暂停不计时；不能把此时间当真人游玩时长。
- 该路线产生 9 次替换，其中包含脚本重新捡起换下器官的往复，**不是 9 次有意义的真人取舍**。
- 此次路线的组合触发为 0：说明基础射击已经能完成非 Boss 路线。不能仅凭通关宣称构筑有趣；这也明确了下一轮需要观察的设计风险。
- 受控浏览器夹具通过 **14 项断言**：实际 Shift 冲撞充能、第五发放电、印记传播与传导、装配面板关闭、满槽替换、撤离中断、成功结算、只结算一次、下一局清槽保留捷径、重开关闭结算面板、死亡保留旧收益、刷新中断、旧灰盒入口、旧战斗入口。
- 印记夹具中记录 15 次射击、14 次命中、8 次传导目标与 3 次传播目标；这里只证明因果链实际执行。
- 试玩反馈 JSON 下载成功，并核对包含反馈文本、路线事件、指标与最终结果。
- 最终功能场景检查未发现浏览器控制台错误。

脚本通过 Playwright CLI 的 `run-code --filename` 执行，截图位于 `output/playwright/`。

- `scripts/slice-first-room.js`：实际键鼠移动、进入西线、跳跃、击杀、拾取、接入暂停、Tab 地图。
- `scripts/slice-full-loop.js`：读取位置辅助导航，通过普通键鼠操作走完整条双线出行；不改生命、敌人或给予模块。
- `scripts/slice-browser-scenarios.js`：受控夹具隔离验证冲撞充能、放电、印记链、满槽替换、撤离结算、存档、死亡、中断与历史入口。这部分会设置初始战斗状态，不能当作正常玩家通关证据。
- `scripts/slice-boss-check.js`：预配模块与充能，实际键鼠攻击完整母巢遭遇，检查母体预警、远程弹丸、奖励和击杀后仍需撤离。

操作脚本是功能验收，不是人类玩家。尤其不能把脚本耗时、精确瞄准、读取状态来找目标，当作新手难度或留存数据。

## 下一轮真人测试

建议让 3–5 名未读设计文档的玩家各玩 2–3 局，记录第一次看不懂／操作不顺的位置，以及到运输枢纽后继续或撤离的理由。结算页可写反馈并导出本局 JSON；文件包含路线、生命／收益节点、装配与替换、组合触发统计和结局。

优先判断：

1. 基础射击和闪避是否有回应，预警是否足够清楚。
2. 两种组合是否真正改变走位和选敌，而非只是伤害更高。
3. 第七件模块是否值得犹豫，或两套核心模块六个槽就能全部装下、缺少取舍。
4. 回路图是否提供足够的撤离诱惑；第二局修复捷径后是否改变路线。
5. 清理后的回程是否过于机械。

## 当前边界

- 使用复用的程序化美术与音效，尚未接入新的正式角色动画、场景美术或 PSD。
- 地图是一屏区域构成的小型连通图，不是最终连续大地图。
- 携带者视觉标识与掉落确定；器官尚未全面改写宿主自身行为。
- 敌人位置只做小幅变化，同一出行内不刷新；回程没有追兵。
- 累计样本是收益记录，研究是器官档案；本轮唯一改变后续路线的永久收益是运输捷径。
- 六槽均为通用槽，核心两条链可以同时装下。是否需要进一步互斥、资源竞争或调整模块，必须看真人取舍行为后决定。
- 不包含热量／体力系统、角色独有技能、完整武器成长、居民与设施经济。
- 有一个可选母体，但没有丰富 Boss 招式阶段。当前不宣称已经完成难度平衡或验证长期耐玩。

构建中的 Phaser 分包体积提示来自现有引擎体积，不是构建失败。
