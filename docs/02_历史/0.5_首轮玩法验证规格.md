# 永蚀 1 · 首轮玩法验证规格

> 历史版本 0.5。当前模块、武器、训练规则以 [0.6 扩展说明](无尽训练场与武器验证_0.6.md) 为准；本文保留首轮记录。

版本：0.5，2026-09-22。基于《永蚀设计概述_用户原文.txt》补充。

本文把尚未明确的规则落成首轮实验假设，不替代完整游戏的最终设计。对应本项目默认浏览器入口；`?legacy` 是旧版房宿灰盒，`?combat` 是旧五房战斗测试场。

## 1. 这轮要回答什么

核心体验：为了想要的能力猎取特定敌人，依照途中收获调整六槽组合；组合改变战斗行为和路线，已经拿到的收获让玩家犹豫是否继续深入。

| 假设 | 实际观察 | 失败信号 |
| --- | --- | --- |
| 基础操作足以承载动作战斗 | 新玩家能自主移动、瞄准、跳跃和闪避，理解受伤原因 | 只看数值换血；无法读懂攻击预警；移动或平台阻塞导致放弃 |
| 模块改变行为，而不仅是战斗时间 | 撞墙流主动调整站位；印记流改变选敌顺序 | 装配前后始终站定按住射击，组合效果无法解释 |
| 猎取能影响路线 | 玩家为某个模块选择西／东线，或者绕行另一侧补齐组合 | 路线只由离门远近决定；无法识别携带者 |
| 六槽形成取舍 | 第七件有吸引力的器官出现时，玩家能说出保留与替换理由 | 总能无脑装下所有核心效果；候选模块没有吸引力 |
| 撤离有可理解的理由 | 玩家结合生命、治疗、收获和目标决定退回或继续 | 每局只把 Boss 当作终点，或任何时候都没有值得带回的东西 |
| 固定地图支持短期重玩 | 连玩三局后利用路线知识、调整构筑、使用解锁捷径 | 第二局开始只是执行同一套最优路径 |

本轮不能证明长期留存、完整养成深度、九把武器的平衡、多个角色差异或大型地图规模下的探索体验。

## 2. 冻结范围

- 一名角色，沿用旧原型程序化角色形象；不加入独有技能与养成树。
- HCP-05 手炮一把，IG-02 冲击手雷一件。
- 十种器官，六个通用槽位，单一器官不能重复叠加。
- 七个固定相连区域、两条分岔路线、一个可选母体目标。
- 三种普通敌人职责：接近施压、远程射击、蓄力冲锋；母体混合射击与冲锋。
- 样本收益记录、器官研究档案、一条永久运输捷径。
- 自主撤离、死亡、重玩、中断处理、试玩记录导出。

暂缓热量／散热、体力、冻结、护盾、角色动作回放、其它武器、完整设施经济、人物救援与搬运、剧情、美术生产。本轮保留生命与充能，先验证两条可读的因果链。

## 3. 一局流程与预期决策

1. 从边境气闸出发，六槽为空，生命 100，医疗针 2 支，充能 0。
2. 选择西线获取冲撞／充能组件，或东线获取印记／传导组件。
3. 击杀头顶标明器官的敌人，靠近掉落按 E 查看并接入。查看面板暂停游戏。
4. 深入对应第二个区域补齐主要组合，也可随时沿原路撤回。
5. 两路交汇于运输枢纽。搜索回路图，此时已有明确的永久奖励可以带回。
6. 选择返回、绕另一侧补充模块，或进入母巢争夺额外 180 样本。
7. 回到气闸左侧按住 E 两秒，成功后保存收益和档案；死亡则丢失本局收益。
8. 下一次出行重新猎取模块；若带回回路图，可从气闸直达运输枢纽。

一局时长由选择路线、战斗熟练程度和阅读时间决定，尚未用真人测试校准。首轮不强行用等待或长回程填充时长。

## 4. 输入与基础战斗

| 输入 | 行为 |
| --- | --- |
| A / D | 左右移动，空中可调整 |
| Space | 跳跃，长短按影响高度；有跳跃缓冲和离地宽限 |
| S | 从单向平台下落 |
| Shift | 冲刺约 0.14 秒，冷却 0.68 秒，无敌 0.18 秒 |
| 鼠标 / 左键 | 360 度瞄准；按住连续射击 |
| Q | 朝鼠标方向抛出冲击手雷，冷却 4.5 秒 |
| H | 使用一支医疗针，恢复 40 生命，不超过上限；满血不能浪费使用 |
| E | 靠近器官／箱子／门时交互；在气闸按住以撤离 |
| Tab | 地图与当前模块说明，暂停战斗 |
| Esc | 暂停／关闭面板 |
| M | 静音 |

### 手炮

- 本轮将原文的连续点按改为允许按住连射，以减少反复点击负担；这是需要试玩确认的临时输入假设。
- 基础每 0.235 秒一发，普通发 14 伤害，每第五发自动重击，28 伤害。跨区域保留当前发数。
- 基础射击不需要弹药，不引入热量；子弹速度 930，受实体地形和平台阻挡。
- 安装放电髓且第五发发射时有充能，自动消耗 1 点，将本发提升至 60；命中敌人后对 140 半径内其他敌人造成 35 伤害与击退。
- 发射出去但没有命中仍然消耗充能。没有独立重击按钮；此次专门验证原文手炮的第五发结构。

### 手雷、受击与地形

- 手雷飞行约 0.65 秒或碰到平台时爆炸；160 半径内造成 12 伤害和强击退。
- 攻击不限制移动；冲刺优先控制速度。暂无复杂攻击取消窗口。
- 一般受击有 0.65 秒无敌时间，防止接触瞬间叠加伤害。
- 敌人普通移动接触不造成伤害；近战伤害只发生在蓄力之后的冲锋窗口，远程伤害来自可见弹丸。
- 场景矮墙可跳过，并用于制造横向撞墙；单向平台不能用作横向撞墙。
- 爆炸和印记传播按半径作用，不做遮挡检查。这是本轮简化；直接子弹仍然需要通路。

这些数值是可调的初始值，不是完成平衡的正式数值表。权威配置在 `src/slice/config.ts` 和 `src/slice/SliceWorld.ts`。

## 5. 十种器官与触发边界

| 器官 | 对应原文模块 | 实际规则 |
| --- | --- | --- |
| 冲撞腺 | 22 | 冲刺接触造成 12 伤害并击退；每次冲刺对每名敌人只触发一次 |
| 压电骨 | 8 | 被玩家明显击退的敌人撞实体墙／边界：充能 +1，最大 3，并眩晕 0.8 秒；每个敌人间隔 0.9 秒 |
| 放电髓 | 25 | 第五发有充能则消耗，提升直接伤害并产生范围冲击 |
| 刻印眼 | 15 | 对同一目标每三次直接子弹命中，施加 8 秒印记 |
| 共鸣索 | 19 | 直接命中已经带印记的目标，向 320 距离内其它印记目标传导本次伤害的 60% |
| 播种囊 | 21 | 带印记目标死亡时，给 280 距离内其它目标施加 8 秒印记 |
| 疾搏心 | 1 | 射速提高 25% |
| 回生膜 | 23 | 击杀恢复 5 生命，不溢出转换 |
| 增压筋 | 3 | 玩家造成的击退提高 65% |
| 裂心瓣 | 5 | 最大生命降至 70，射速提高 40%；卸下恢复上限但不补血 |

触发边界：

1. 传导只复制伤害，不复制击退、命中次数和其它攻击事件，不递归传导。
2. 刻印眼第三次命中刚施加的印记，从后续直接命中起可触发共鸣索。
3. 传导／范围伤害可以击杀并触发回生膜、播种囊，但不会增加三击计数。
4. 击退要实际撞到墙，贴墙行走或重复每帧碰撞不会自动刷充能。
5. 母体受到的击退减半。
6. 两个射速模块按乘法叠加；其它器官不重复叠加。
7. 充能可以暂存；暂未安装放电髓时不会随第五发消耗。

## 6. 获取、装配和选择节奏

- 携带者头顶显示准确器官名称，外置发光节点以颜色区分构筑类别。
- 击杀确定掉落该器官。首轮不加入掉率，避免无法判断是组合不成立还是根本没拿到。
- 每局相同生态与器官来源，敌人出生横坐标按出行序号小幅变化；不宣称具有丰富的随机生态。
- 按 E 打开查看面板时暂停；有空槽就接入空槽，满六槽选择替换。换下器官留在原地，可回头拿。
- 同种不能重复接入，没有额外模块背包；地面器官不会过期或被普通子弹毁掉。
- 掉落落在对应位置的地面，避免浮空敌人的器官无法取得。
- 地图连通允许遍历两路，整局有十种候选器官。只跑单路并早撤可能尚未遇到第七种，这是允许的。
- 面板里的装配暂停是可用性假设；如果大量暂停破坏动作节奏，再测试脱战装配或快捷替换，首轮不同时实现多个方案。

## 7. 固定地图

```text
            压电采掘场 ↔ 废弃锻造井
           ↗                      ↘
边境气闸                            运输枢纽 ↔ 永蚀母巢
           ↘                      ↗
            回声培养廊 ↔ 菌群共鸣室

永久解锁后：边境气闸 ↔ 运输枢纽
```

| 区域 | 主要器官／奖励 | 用途 |
| --- | --- | --- |
| 气闸 | 无敌人，安全撤离 | 出发、选线、结算 |
| 采掘场 | 冲撞腺、压电骨、增压筋，35 样本箱 | 学习击退与撞墙 |
| 锻造井 | 放电髓、裂心瓣、疾搏心，70 样本箱 | 完成充能链，面对矮墙与远程压力 |
| 培养廊 | 刻印眼、共鸣索、回生膜，35 样本箱 | 学习印记与选敌 |
| 共鸣室 | 播种囊、疾搏心等，70 样本箱 | 完成传播链，群体战 |
| 枢纽 | 增压筋、裂心瓣，90 样本与运输回路图 | 明确撤离诱惑，分流与换线 |
| 母巢 | 母体额外 180 样本，附带普通敌人 | 可选高风险挑战，不锁门 |

每个区域是一屏战斗空间。切换时保留该区剩余敌人生命、掉落、搜索状态；不回满玩家生命、不刷新已杀敌人。清空在途子弹，入区给予短暂无敌，避免加载后立刻受击。跨区临时敌人状态在离开期间冻结。

首轮暂不加入回程追兵或全局倒计时。已清理路线回程较安全，因此这一版主要验证是否深入与构筑取舍，不能代表最终撤离压力。若真人普遍认为返程只是跑路，优先改回程结构，而不是直接加大地图。

## 8. 收益、失败和永久进度

- 普通击杀立即将少量样本计入本局携带量，搜索箱子获得更多；器官需要单独接入。
- 成功撤离：本局样本加到累计带回记录；撤离时六槽内的器官记入研究档案；回路图修复永久捷径。
- 死亡：本局所有未结算样本、回路图与器官丢失，已经带回的档案和捷径保留。
- 下一局：角色基础生命、武器保持相同，槽位清空。当前“研究”只收录原理，没有永久战斗属性，避免提前替代局内猎取。
- 样本累计暂为验证收益记录，没有消费商店；真正改变下一局路线的永久收益是运输捷径。
- 新存档键为 `ever-eclipse-slice-v1`，与旧模式隔离；新模式不覆盖旧原型进度。
- 点击开始标记未完成出行；刷新或关闭未完成出行视为中断，未结算收益丢失。暂停不结束出行。
- 浏览器禁止本地存储时仍可完整单局试玩，界面会说明无法保存。

## 9. 复用与实现对应

复用旧 `Player.ts` 的移动／跳跃／冲刺，`PhysicsHelpers.ts` 的 AABB 与扫掠碰撞，`Enemy.ts` 的实体，`Renderer.ts` 的程序化角色、敌人、场景、伤害数字、特效，`Effects.ts` 的合成音效，以及 `World.ts` 的基础受击／反馈功能。

新实现：

- `src/slice/config.ts`：器官、地图与敌人携带配置。
- `src/slice/SliceWorld.ts`：六槽、两套触发链、敌人行为、旅行、搜索与撤离。
- `src/slice/SliceScene.ts`：键鼠、地图、说明、结算、存储与导出。
- `src/slice/slice.css`：新模式 UI。

这轮没有把 PSD、角色分件图等直接当作动画资产接入；旧浏览器版本本来使用程序化美术，因此先复用其中可直接运行的画面与动作。

## 10. 真人试玩方法

先邀请 3–5 名未读完整设计文档的玩家，各玩 2–3 局。不给最优解，不远程指导每一步。结算时写简短反馈并点击“导出本局试玩记录”。JSON 保存在本地下载目录，不上传。

依次观察：

1. 首次进入西／东线、首次击杀、首次接入有没有理解障碍。
2. 能否根据目标器官说出想去的路线。
3. 一条组合成型后，实际走位、选敌或开火是否改变。
4. 第七个候选模块出现时，是否有真实取舍。
5. 到枢纽拿到回路图后，是否重新评估继续与撤离。
6. 第二局是否愿意主动尝试另一条路线，或利用永久捷径。

日志记录时间、路线及当时生命／收获、装配与替换、搜索、手雷、治疗、Boss 与最终结果；汇总记录射击／命中、撞墙充能、放电命中、传导目标次数、传播目标次数、受伤量与换槽次数。传导／传播统计是作用目标次数，不是独立施放次数。

自动测试与浏览器操作只能证明功能闭环和部分可达性，不能据此宣称游戏已经好玩。结合日志和观察，优先调整基础战斗、模块反馈、敌群配置和决策节点；不要在这些问题没回答前扩大设施与角色数量。
