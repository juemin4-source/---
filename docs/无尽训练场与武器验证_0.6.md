# 永蚀 0.6 · 无尽训练场与武器验证

2026-09-23。此版本取代 0.5 对「十种器官、单一主武器、有限敌人」的冻结范围。设计原文保持原样；下文为已经实现的原型规则与可调数值，不是正式版平衡结论。

## 进入与操作

运行 `npm run dev`，打开本地地址，选「进入无尽训练场」。先在训练台选组合、叠层、武器和敌人，再按「继续战斗」。B 随时打开训练台，训练场 Tab 也可打开；开台时暂停战斗。

| 输入 | 行为 |
| --- | --- |
| A / D、Space、S | 移动、跳跃、下落平台 |
| Shift、F | 消耗体力冲刺；空中下砸 |
| 鼠标、左键 | 瞄准、主武器攻击 |
| 1–5 | 手炮、步枪、狙击、匕首、重锤 |
| 6–9 | 盾、手雷、无人机、炮台 |
| 右键、Q | 持盾格挡；投掷或部署副武器 |
| E、H | 接入掉落、治疗 |
| B、Esc、M | 训练/配装台、暂停、静音 |

训练死亡可保留武器和模块层数继续，或调整配置后再战。训练不增加探索存档的样本、研究和出行次数。刷新会重置本次训练，可从暂停或结算页导出 JSON 记录。

## 训练场不会打完就没怪

- 默认每波基础 5 只、初始生命倍率 3 倍；每三波再多一只。清场 1.2 秒后续波；未清场时每 22 秒增援。
- 第 n 波生命倍率为 `起始倍率 × 1.22^(n−1)`；伤害倍率为 `1.08^(n−1)`，最高 20 倍。敌人生命倍率技术上限一亿，非通关目标。
- 最多同时 28 个存活敌人，满员暂停增援，腾出位置后继续。长期战斗清理死亡实体、过期伤害数字和日志，防止无限积累。
- 混合模式轮换近战爬行者、冲锋回收者、浮游射手，每五波加入母体。也可只刷任意一种，包括母体。
- 训练台可设起始生命倍率 1–1000、基础数量 1–24、当前波次 1–100、指定掉落器官，或关闭自动刷怪。设置只影响之后召唤的怪；要立即对比，先清场再召唤。
- 「立即召唤」不增加波次；「开始下一波」增加波次并按新强度召唤。清除当前敌人不计击杀。
- 可补满生命、体力、手雷以外的无人机储备与治疗次数；补给同时清热、补充能。手雷仍遵循冷却。

## 六槽与同类叠层

六槽限制**不同模块种类**。已有种类再次拾取会自动加层；第七种仍需选择替换。换下来的整组层数落地，重新接入会恢复整组，不能复制层数。

训练台可直接接入任意模块，每次 1–100 层；可继续追加。六个组合预设也使用所填层数。探索模式配装台只换武器，模块继续从敌人掉落取得。

采用逐项定义叠层收益的做法，未假定所有效果都是伤害乘法。以下 n 为层数；同类攻速收益相加，多个直接伤害条件的增幅相加。界面卡片显示当前层数对应的数值。

| 模块 | 实装叠层规则 |
| --- | --- |
| 冲撞腺 | 冲刺接触伤害 12n；同次冲刺每目标一次 |
| 压电骨 | 击退撞墙 +n 充能；容量 3+2(n−1) |
| 放电髓 | 重击消耗 1 充能：直接伤害 +32n，范围放电 35n |
| 刻印眼 | 每 `ceil(3/(1+0.35(n−1)))` 次直接命中挂印，最低一次；持续 8+2(n−1) 秒 |
| 共鸣索 | 传导本次伤害的 60%+30%(n−1)；传导不递归 |
| 播种囊 | 标记目标死亡传播半径 280+60(n−1)，传播印记持续 8 秒 |
| 疾搏心 | 攻速 +25%n；匕首节拍最多加速两倍 |
| 回生膜 | 击杀治疗 5n |
| 增压筋 | 击退 +65%n |
| 裂心瓣 | 生命上限 `100×0.7^n`，最低 10；攻速 +40%n |
| 震荡肺 | 重击范围伤害 35%+15%(n−1)，半径 105+35n |
| 燃盾囊 | 有盾时直接伤害 +50%n；护盾额外每秒消耗 12n |
| 瞬息核 | 冲刺无敌窗口躲过实际命中 +n 充能，每次冲刺一次 |
| 回流腱 | 把未眩晕目标打入眩晕，恢复 12n 体力 |
| 浮游鳍 | 空杀获得一次凌空跳，储存上限 n；空中跳跃消耗 |
| 灼心腺 | 热量达到 60，直接伤害 +35%n |
| 张力筋 | 体力至少 95，近战/范围攻击半径 +30%n |
| 冷凝膜 | 热量曾达到 60，降至 35 时获得 25n 护盾 |
| 痛觉腺 | 每损失 1% 生命，直接伤害 +0.8%n |
| 泄压阀 | 重击命中印记目标消耗印记，散热 25n |
| 凝霜髓 | 直接命中积累 n，满 5 冻结；持续 1.5+0.25(n−1) 秒 |
| 崩解筋 | 眩晕目标击退 +100%n |
| 裂隙牙 | 重击使目标后续伤害 +20%n，持续 4 秒 |
| 碎晶核 | 重击消耗冻结，范围伤害 45n；半径 170+30(n−1) |
| 蓄生囊 | 溢出治疗按 100%n 转护盾，护盾总量上限 1000 |
| 天穹翼 | 凌空直接伤害 +30%n、攻击范围 +20%n |
| 坠星骨 | 下砸高度 h：伤害 30+0.2hn，半径 90+0.45hn，击退 250+hn |
| 群猎眼 | 每多命中一个目标增伤 15%n；穿透按已经穿过的目标逐步增加 |

护盾基础衰减 1/秒。敌人最终水平击退限幅 3200，母体承受的击退减半。间接范围伤害、传导不会重新递归挂印或冻结；无人机和炮台子弹算直接命中，可以参与构筑。

## 怎么用它回答玩法问题

先在同一敌人配置下，用同一武器比较空模块、预设一层、预设三层，再只改一种模块。HUD 可观察五秒 DPS、撞墙、传导、冻结和碎冰次数；导出记录保留武器、层数、波次和事件。

建议分别试「撞墙放电」「印记连锁」「冻结碎冰」「高热循环」「回生燃盾」「凌空猎杀」。成型后继续提高生命倍率或波次，观察是否仍需要走位、换目标和管理热量/体力。允许出现超强组合，先收集它为什么强、什么时候失效的证据，再谈削弱。

本轮解决了“没有足够战斗对象去试构筑”的验证障碍。真人仍需回答：成型后是否想继续打一波；叠层是否改变动作选择；不同武器是否适配不同组合；强度提高后是否只剩血量变厚。无尽训练不能单独证明搜打撤的路线选择、损失压力和长期培养好玩，原七区探索入口继续保留，其投放仍是原十种模块。

## 验证记录

- `npm test`：92 个测试，包括新增 13 个训练/武器/组合行为测试与 Boss 长时间物理回归。
- `npm run build`：TypeScript 和生产构建通过；Phaser 分包仍有体积提示。
- `scripts/slice-training-browser.js`：20 项浏览器检查通过。真实点击训练台、输入层数和敌人设置、键盘切换九武器、鼠标重锤冻结碎冰、Q 部署、暂停、自动续波均已执行。
- 浏览器中的三只 Boss 经模拟 60 秒反复击退，底部都保持在地面 610，未出界；此次修复根因是母体高度不同却沿用普通敌人出生中心，导致嵌入地面后被碰撞推出。
- 浏览器战斗使用受控敌人位置、生命和无敌设置验证机制，不是无辅助通关，也不是“已证明好玩”的试玩结果。
